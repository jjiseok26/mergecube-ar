실선 바깥 = 자르기 · 날개와 면 사이 점선 = 접기 · ‘풀’ 날개 = 안쪽에 풀을 발라 붙이기

  1. 실제 크기로 인쇄하세요. 페이지 맞춤 축소는 인식률을 떨어뜨립니다.
  2. 바깥 실선을 따라 자르고, 풀 날개는 사다리꼴 모양 그대로 남깁니다.
  3. 면과 면, 면과 날개 사이의 점선을 산 접기로 접습니다.
  4. 날개 안쪽에 풀을 바르고 마커가 바깥을 향하게 정육면체로 붙입니다.
  5. 두꺼운 종이에 붙이면 손에 쥐고 돌리기 좋습니다.
