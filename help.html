인쇄한 큐브 위에 모델을 올립니다.

스튜디오 큐브 인쇄 AR 보기

이용 안내

큐브를 인쇄해 접은 뒤, 면에 모델을 올리고 태블릿 카메라로 보면 됩니다.

1. 큐브 만들기

  1. 큐브 인쇄를 열고 인쇄합니다. 페이지에 맞게 축소하지 마세요. 마커가 작아지면 인식이 잘 안 됩니다.
  2. 바깥 실선을 자르고, 면과 날개 사이 점선은 산 접기합니다.
  3. 풀 날개 안쪽에 풀을 발라 마커가 바깥을 보게 정육면체로 붙입니다.

2. 모델 올리기

  1. 스튜디오에서 큐브 면이나 오른쪽 칸을 눌러 면을 고릅니다.
  2. GLB 하나를 올리거나, glTF와 같은 폴더의 .bin, 텍스처를 함께 올립니다. 폴더째 놓아도 됩니다.
  3. 크기, 위치, 회전은 그 면에만 적용됩니다. 면에 맞추기는 모델을 면 위에 다시 앉힙니다.
  4. 모델의 색, 무늬, 금속·거친 정도는 파일에 들어 있는 그대로 보입니다.

3. 태블릿에서 보기

  1. 태블릿 QR을 누르고, 나온 주소가 https로 시작하는지 확인합니다.
  2. 태블릿은 같은 네트워크에서 Safari 또는 Chrome으로 엽니다. 카메라 앱이나 카카오톡 안의 브라우저에서는 카메라가 막힙니다.
  3. AR 보기에서 카메라 시작을 누르고, 큐브 한 면이 화면을 크게 채우게 비춥니다.
  4. 화면 아래 버튼으로 모델을 돌리고, 옮기고, 키우거나 줄일 수 있습니다. 버튼을 누르고 있으면 계속 움직입니다. 한 번 인식되면 마커가 잠깐 벗어나도 화면에 남습니다. 모델을 짧게 누르면 이 화면에서만 지워지고, 스튜디오에 저장된 모델은 그대로입니다.

4. 카메라가 안 켜질 때

  • 주소가 http이면 카메라를 쓸 수 없습니다. QR을 다시 만들어 https 주소로 여세요.
  • 보안 경고가 나오면 고급을 누른 뒤 계속 또는 방문을 선택합니다.
  • 권한을 거절했다면 주소창의 사이트 설정에서 카메라를 허용한 뒤 새로고침합니다.
